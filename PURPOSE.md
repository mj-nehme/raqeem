# Project Purpose

Raqeem is an educational, open-source project used for teaching and learning.

Focus areas:
- IoT device monitoring and telemetry flows
- Cloud-native backend patterns (APIs, storage, containers)
- Practical CI pipelines and testing strategies across Python, Go, and JS

This codebase is not production-ready. If you plan to use it beyond learning:
- Review and harden security, authn/z, and secrets management
- Validate scaling characteristics and persistence guarantees
- Configure observability and SLOs for your environment

See `docs/` for architecture, APIs, and development guides.
